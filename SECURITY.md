# Security Policy

QDSV Bridge accepts compact semantic problem specifications, not raw datasets.

Do not publish API keys, license keys, private URLs, datasets or credentials in issues, examples or pull requests.

## Reporting Security Issues

Please do not open public issues for sensitive security concerns.

Use the contact form at https://qdsv.cloud/ or contact the project maintainers privately.

## Public Service Boundaries

Bridge public endpoints support bounded semantic specifications and portable
artifact workflows. Do not send sensitive records, credentials, raw datasets or
regulated information to a public endpoint. Provider execution and hardware
credentials remain outside the SDK boundary and must be handled by the
consumer or an authorized Qruba/QDSV workflow.
